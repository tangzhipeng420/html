3客户场景诊断：5步问诊

1️⃣ 你家现在有没有宽带？没有 → 单C套餐（全家享39/59）；有 → 继续问
2️⃣ 家里WiFi信号好不好？组网了吗？不好/没组网 → 爱家79或99（带WIFI6）
3️⃣ 家里几口人用手机？要不要全家共享？多人 → 选可共享套餐，副卡功能费还能免1-2张
4️⃣ 平时流量够用吗？刷视频多不多？流量少 → 79/139；流量多 → 99/119/169
5️⃣ 对网速有要求吗？要不要全屋无死角？要 → FTTR版（139FTTR 129元 / 169FTTR 159元）
问诊口诀：宽带→WiFi→人数→流量→网速，5个问题定套餐，别让客户自己挑。

4三大主推 + 组合公式

主推1 · 爱家99（69元）— 标准家庭首选
卖点：69元 = 217.5G（通用67.5G可共享）+400分钟+300M宽带+电视免1年+WIFI6，单办宽带电视都不止这个价。
适用：有宽带、有WiFi、多人共享的普通家庭，覆盖面最大。
主推2 · 爱家139FTTR（129元）— 高价值家庭收割
卖点：129元 = 325G+900分钟+1000M+电视+FTTR一套（FTTR单办560元/年），网速全屋无死角。
适用：流量大、对网速有要求、月消费高的家庭，一单顶几单。
主推3 · AI小福袋 — 全场景终端钩子
卖点：19-59元/月×36月，首付300元拿5G手机，价格计入共享保底，任何套餐都能叠。
适用：携转客户换机刚需，配39档小福袋最主流。

组合公式

🔹 纯手机客户：全家享39/59 + 小福袋39档
🔹 标准家庭：爱家99(69元) + 小福袋29档 + 政企存100（送空气炸锅/电饭煲）
🔹 高价值家庭：爱家139FTTR(129元) + 小福袋59档 + 云终端PAD/旗舰机购机
🔹 政企客户：98+套餐 + 宽带 + 政企存100/200

5标准话术

开场（携转客户）："您好，您转移动的话，我帮您配一个全家套餐：宽带、电视、WiFi都包在里面，一个月69块钱，全家人手机流量还能共享，比您现在单交宽带费还划算。"

推爱家99："69元/月，217G流量，其中通用流量67G全家随便用还能共享，另外送50G夜间+100G视频定向；300M宽带、电视第一年免费、再送一台WiFi6路由器。单办300M宽带加电视一个月都不止69。"

推爱家139FTTR："您家对网速要求高，这套129元的：千兆宽带+FTTR全屋覆盖，每个房间都是满信号，325G流量其中通用125G全家共享，电视第一年免费。"

推小福袋："再帮您配一台5G手机，月供才29块钱，合约36个月，首月300元定制服务费就行，手机是全新的，还能算进您的共享保底里面。"

6办理注意事项（坑要提前说）

事项规则
